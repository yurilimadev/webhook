# Desafio Webhook HashTag Treinamentos

- Contexto

A vida me trouxe de volta aqui com outra maturidade técnica. Em 2023, eu era aluno da Hastag Treinamento e tinha acabado de conseguir meu certificado de Python Impressionador e, realmente, acreditava que entendia tudo que foi passado no curso. 

Bem, como vocês podem imaginar, estava tendo sintoma da Sindrome de Dany Kruger. Jurava mesmo que eu tinha entendido das conceitos, mas na verdade, eu só sabia fazer programação funcional... 😭👍

Descobri isso, quando me deparei com esse desafio técnico de fazer um Webhook. Confesso, que eu tinha uma tendência de complicar as coisas na minha cabeça e achei que não tinha entendido ou não ia entender.

Mas, como eu disse no começo desse texto, precisei de 3 anos e dois dentro de uma faculdade de TI para criar coragem e revisitar esse repositório começar esse projeto do zero. 

A ideia é fazer esboço manualmente e deixar algumas atribuições de frontend e dados mockados para Inteligencia Artificial(IA). Afinal, as regras jamais devem ser terceirizadas 100% para a IA. 

Então, que comece novamente esse desafio.
